Who shipped first?

For each web feature, which browser engine shipped it first: Chromium (Chrome and Edge), Gecko (Firefox) or WebKit (Safari)? Desktop releases only, discouraged features excluded, using the release date of the first version that supports each feature in the web-features dataset.

Features that any engine already supported by {{ shipped.cutoff }} are ignored ({{ shipped.skippedLegacy }} features): Safari and Firefox were around for years before Chrome existed, so crediting them with those says nothing about who innovates first. When the earliest engines shipped a feature in the same month, it's treated as a concerted launch and no engine gets credit. Data generated on {{ shipped.generated }}; {{ shipped.skippedApproximate }} features were left out because their first version is only known approximately (e.g. “≤79”).
