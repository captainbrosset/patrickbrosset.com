Use with GarageBand on a Mac
  1. Open Audio MIDI Setup, then Window → Show MIDI Studio.
  2. Double-click IAC Driver and tick "Device is online".
  3. Click "Enable WebMIDI" above and allow the browser prompt.
  4. Set Output to "IAC Driver Bus 1".
  5. In GarageBand, select a software instrument track. Tap the pads to play it.

Pad notes start at 36 (C2). Change them per pad in Edit mode. To avoid double sounds, turn off "Play internal sounds" and do not send GarageBand's output back to BeatPad.
