--- layout: slide.njk title: Fun never gets old - Oredev 2026 - Users need the web to evolve notes: | User needs never stop evolving. The ever-growing web reaches more and more of the world, which means that everyday there's a new market to reach, a new geography and its culture to adapt to, new user habits and expectations to understand. So there's never a point at which the web is simply "done." Sure, keeping up with this rapid evolution is uncomfortable. There are new things to learn all the time, new APIs that appear, old patterns that change, new best practices to learn, and so on. But this happens for a reason. Any application platform, and the web is the most successful one ever, must continuously evolve to meet the changing needs of its end users. This is of course particularly true for something as ubiquitous as the web, which has effectively become our window to almost everything we do on our devices. ---
