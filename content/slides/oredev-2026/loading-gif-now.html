--- title: The need stayed, the tools changed notes: | Again, the web platform caught up. CSS has come a very long way. We have animations, gradients, transforms, masks, clipping paths, and all sorts of drawing primitives. With just a few lines of presentation code, we can build animations that are responsive, themeable, and highly interactive. We can even respect the user's reduced-motion preference. The user need stayed the same; but our tools got better. Developers pulled the web forward by making the need visible and addressable. ---
